# Корпоративний Патронус

Статичний квест. Відкривається з `index.html`.

Щоб отримати посилання:

1. Створи репозиторій на GitHub.
2. Залий у корінь файли сайту, не архів: `index.html`, інші сторінки, `styles.css`, `room.js`, `choice.js`, папку `images`.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. За кілька хвилин сайт буде за адресою `https://ТВІЙ-НІК.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.
